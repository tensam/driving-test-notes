# Cannabis Effect on Driving - Increases Sleepiness

## Question
How does cannabis affect driving?

## Options
- **A) It increases sleepiness.** ✅
- B) It reduces reaction time.
- **C) It reduces sleepiness and concentration.** ❌ (my answer)

## Correct Answer
A — It increases sleepiness.

## Why I Got It Wrong
C 选项把两个效果混在一起："reduces concentration"是对的，但"reduces sleepiness"（减少困倦）是反的。大麻让人更困，不是更清醒。一对一错 = 整个选项错。

## Key Rule
大麻对驾驶的影响：
- **增加**困倦（sleepiness）
- **降低**注意力（concentration）
- **增加**反应时间（reaction time 变慢）

注意 B 选项 "reduces reaction time" = 缩短反应时间 = 反应更快，这也是错的。

## Key Vocabulary
- cannabis = cannabis = 大麻
- sleepiness = somnolencia = 困倦
- increases vs reduces：方向要看清
