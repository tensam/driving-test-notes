# Tunnel - Dipped Headlights Compulsory

## Question
Must the dipped headlights be on in a tunnel which is sufficiently lit?

## Options
- **A) No, the tunnel is lit.** ❌ (my answer)
- B) No, the high-beam headlights must be on.
- **C) Yes, this is compulsory.** ✅

## Correct Answer
C — Yes, this is compulsory.

## Why I Got It Wrong
觉得隧道已经有照明了就不需要开灯。实际上无论隧道照明条件如何，进入隧道必须开启近光灯，这是法律强制要求。

## Key Rule
隧道 = 必须开近光灯，不看照明条件：
- 开灯不仅是为了自己看路，也是为了**让其他车辆看到你**
- 用近光灯（dipped），不是远光灯（high-beam），远光灯在隧道内会造成眩光
- 这是强制性规定（compulsory），没有例外

## Key Vocabulary
- dipped headlights = luces de cruce = 近光灯
- sufficiently lit = suficientemente iluminado = 照明充足
- compulsory = obligatorio = 强制的
