# 蓝圈moped标志 = 只有moped专用

## Question
What does this sign mean at the start of a route? (蓝圈+moped图案)

## Options
- **A) No mopeds**
- **B) Mopeds only** ✅
- **C) Reserved for cycles and mopeds** ❌ (my answer)

## Correct Answer
B) Mopeds only

## Why I Got It Wrong
记得有个标志是自行车+moped都可以的，但这题图里只画了moped没有自行车。R-407a（自行车道）和R-407b（moped道）是两个独立标志，不存在合体标志。

## Key Rule
- R-407 a：蓝圈 + 自行车图案 = 自行车道（cycle path）
- R-407 b：蓝圈 + moped图案 = moped道（moped track）
- 蓝圈 = 专用道，图里画了什么就是什么的专用

## Key Vocabulary
- moped = 轻便摩托车（≤50cc）
- cycle = 自行车
