# 红灯+绿箭头能否直行

## Question
The red traffic light and the green arrow are lit. Is it possible to drive on?

## Options
- **A) Yes** ❌ (my answer)
- **B) No** ✅
- **C) Yes, but in the left lane**

## Correct Answer
B) No

## Why I Got It Wrong
两个理解错误：
1. "drive on" 以为是"还能不能继续开"，实际意思是"能否直行"
2. 没理解红灯+绿箭头组合：红灯=默认全部禁止，绿箭头=只开放箭头指的那个方向

## Key Rule
- 红灯 + 绿箭头 = 只能走箭头方向，其他方向全部禁止
- 绿灯（圆形）= 所有方向都可以

## Key Vocabulary
- drive on = 继续前行/直行（不是泛指"能不能开"）
- green arrow = 方向箭头灯（可以指左、右或直行，不是特指右转灯）
- proceed = 通行（泛指）
